# 🏦 Sistema Bancário em Java

Projeto desenvolvido para colocar em prática meus estudos de **Java** e **Programação Orientada a Objetos (POO)**.

A ideia é evoluir o sistema gradualmente conforme avanço nos estudos, utilizando o próprio projeto como laboratório para aplicar novos conceitos.

## 🎯 Objetivo

Construir uma aplicação bancária simples e, ao mesmo tempo, consolidar os fundamentos de Java através da prática.

## 📚 Conceitos praticados

- Classes e objetos
- Construtores
- Sobrecarga de construtores
- Métodos
- Relacionamento entre objetos
- Composição
- Arrays de objetos
- Estruturas de repetição
- Estruturas condicionais
- Tratamento de exceções
- Organização e refatoração de código

## 🚧 Evolução do projeto

O projeto está em desenvolvimento e acompanha minha evolução nos estudos.

Próximos conceitos que pretendo aplicar:

- Collections
- List, Map e Set
- SQL
- JDBC
- Integração com Banco de Dados
- APIs
- Spring Boot

## 💡 Sobre o projeto

Este não é um projeto desenvolvido com a intenção de representar um sistema bancário real.

Ele é, principalmente, um **projeto de aprendizagem**, utilizado para transformar conceitos estudados em código e acompanhar minha evolução ao longo do tempo.

> Cada funcionalidade representa uma etapa do meu aprendizado em Java.
